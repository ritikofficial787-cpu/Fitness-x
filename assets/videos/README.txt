Place your workout demo video files in this folder.

Currently expected file:
  - jumping_jack.mp4   (for the Jumping Jack exercise video demo)

When you add jumping_jack.mp4 here, the app's Exercise Details screen 
for Jumping Jack will show the video play button.

Until the file is added, the app shows a safe placeholder message:
  "Add jumping_jack.mp4 to assets/videos/"

The app will NOT crash if this file is missing.
