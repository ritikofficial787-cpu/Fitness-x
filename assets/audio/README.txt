SLEEP TRACKER — ALARM SOUND

Place your alarm sound file in this directory:

  assets/audio/alarm.mp3

Notes:
- The file must be named exactly: alarm.mp3
- Supported formats: mp3, wav, aac, ogg
- Recommended: Short alarm clip (3–5 seconds) that the app loops every 5 seconds
- If the file is missing, the app will NOT crash — it falls back to vibration
- After adding the file, run: flutter pub get

Example free alarm sounds can be found at:
  https://freesound.org (search: alarm clock)
  https://pixabay.com/sound-effects/search/alarm/
