                        APP KA NAAM AUR PURPOSE
================================================================================

App Name   : FitnestX
Tagline    : "Everybody Can Train"
Platform   : Flutter (Android + iOS + Web/Desktop)
Language   : Dart (Flutter framework)

Purpose    : Yeh ek fitness tracking app hai jisme user apna workout,
             meals, sleep, aur overall health progress track kar sakta hai.

App Color  : Purple-Blue Gradient (#92A3FD => #9DCEFF)
             Yeh gradient poori app mein consistent use hua hai -
             buttons, cards, icons sab jagah.

================================================================================
               SIGNUP / LOGIN - COMMON QUESTIONS AND ANSWERS
================================================================================

Q1: Kya app mein real authentication hai?
A: Nahi. Koi backend nahi hai. Form validation sirf client-side hai.
   Jo bhi valid email/password daloge, submit hone par direct success milega.
   Real auth ke liye Firebase Auth ya REST API lagegi.

Q2: Password store kahan hota hai?
A: Abhi kahan bhi nahi. Koi database nahi hai.
   Production mein Firebase ya secure backend use karenge.

Q3: Form validation kaise kaam karta hai?
A: Flutter ka Form widget + GlobalKey<FormState>.
   validate() call par sabhi field validators run hote hain.
   Fail hone par error text field ke neeche dikhti hai.

Q4: Kya Google/Facebook buttons kaam karte hain?
A: Nahi. Sirf UI hai. Future mein google_sign_in package se implement hoga.

Q5: Register ke baad login karna padta hai?
A: Nahi. Register => Profile => Goal => Success => Dashboard directly.

Q6: "Forgot your password?" kaam karta hai?
A: Nahi. Sirf underlined text hai. Backend ke bina implement nahi hoga.

Q7: Profile setup mein weight/height kyun maanga?
A: BMI calculate karne ke liye. BMI = weight(kg) / (height(m))^2
   Note: Dashboard par BMI abhi hardcoded hai (20.1).

Q8: Privacy Policy checkbox mandatory kyun hai?
A: GDPR aur Play Store guidelines require user consent.
   Code: agar _agreedToPolicy == false to SnackBar error dikhti hai.

WIDGET              | KYA KARTA HAI
--------------------|---------------------------------------------------------
MaterialApp         | Poori app ka root. Theme, title, home screen yahan.
Scaffold            | Har screen ka base. AppBar, body, bottomNav iska part.
SafeArea            | Content ko notch/camera/status bar se bachata hai.
Column              | Widgets ko upar se neeche ek ke baad ek rakhta hai.
Row                 | Widgets ko left se right side-by-side rakhta hai.
Container           | Box - color, border, padding, size set kar sako.
Text                | Sirf text dikhane ke liye.
SizedBox            | Fixed size empty space. Gaps ke liye.
Padding             | Widget ke bahar space dena.
Expanded            | Available space poora leta hai (Row/Column mein).
Spacer              | Remaining space fill karta hai (Column mein).
ElevatedButton      | Raised button. onPressed se action.
GestureDetector     | Kisi bhi widget ko tappable banata hai.
TextField           | User se text input lene ke liye.
Form                | TextFields ko group karta hai for validation.
ListView            | Scrollable list of widgets.
GridView            | Grid format mein widgets.
PageView            | Swipeable pages (onboarding mein use hua).
Stack               | Widgets ko ek dusre ke upar rakhta hai.
Image.asset         | App ke assets folder se image dikhata hai.
Icon                | Material icons (bell, home, person, etc.).
Checkbox            | Tick karne wala box.
Switch              | Toggle (on/off) switch.
DropdownButton      | Dropdown menu.
CircularProgressIndicator | Spinning/fill circle. Value se fill % set.
LinearProgressIndicator   | Horizontal progress bar.
SingleChildScrollView     | Content scroll ho jaye jab screen se bada ho.
IndexedStack        | Multiple screens, ek waqt ek dikhata hai.
AnimatedContainer   | Smoothly animate hota hai property change par.
CustomPaint         | Canvas par khud se shapes draw karne ke liye.
Navigator           | Screens ke beech navigate karne ke liye.
MaterialPageRoute   | Ek screen se dusri screen ka route.
SnackBar            | Bottom par temporarily dikhne wala message.
showModalBottomSheet | Neeche se utha aane wala popup panel.
showDatePicker      | Built-in date selection calendar dialog.

NAVIGATION TYPES:
  push()               - Naya screen add (back button kaam karta hai)
  pushReplacement()    - Current screen replace (back nahi ja sakte)
  pushAndRemoveUntil() - Sab pehle wali screens hata ke naya screen
  pop()                - Current screen hata ke pichli par jao

CHART LIBRARY: fl_chart (pub.dev/packages/fl_chart)
